# 2022 개정 교육과정 '정보' 교과 성취기준 및 성취수준 분석

정보 교과 평가 문항을 한 문항씩 살펴보며 **그 문항이 겨냥하는 성취기준**을 끌어다 놓고, 이어서 열리는 **성취수준(A~E)** 중 문항이 요구하는 수준을 골라 보는 실습 워크북 웹앱입니다.
연구회 선생님들의 분석 결과를 모아 문항별 통계로 보여 주어, 평가 문항과 성취수준을 함께 협의하는 자료로 활용할 수 있습니다.

**🔗 바로 사용하기: https://info-std-workbook.vercel.app**

> 제작: **2026 정보교육나침반 연구회**

---

## 주요 기능

| 구분 | 내용 |
|---|---|
| 📚 영역별 문항 | 5개 영역, 총 182문항을 원본 이미지 그대로 수록 |
| 🧩 2단계 분석 | ① 성취기준 카드를 상자로 드래그(또는 탭) → ② 해당 성취기준의 A~E 성취수준 선택 → 분석 근거 메모(선택) |
| 🗂 목록 이동 | 영역별로 접고 펼치는 문항 목록, 이전·다음 문항, 뒤로 가기, 이어서 하기 |
| 💾 기록 저장 | 브라우저에 자동 저장, 기록 초기화, 기록 백업(.json)·불러오기 |
| 📄 결과 PDF | 이름·소속을 넣어 분석 결과 보고서를 PDF로 다운로드 (문항 이미지 포함 선택 가능) |
| 📮 결과 전송 | 모든 문항을 마치지 않아도 선택한 만큼 전송, 다시 보내면 최신 결과로 갱신 |
| 📊 통계 대시보드 | 참여자 수, 영역별 성취수준 분포, 문항별 성취기준 선택 비율·합의도, 성취수준 도넛 그래프, 내 선택과 다수 의견 비교 |
| 📱 편의 기능 | 모바일 자동 배율, 문항 이미지 확대/축소, 버튼 효과음(끄기 가능), 파스텔 핑크·라벤더 디자인 |

## 사용 방법

1. https://info-std-workbook.vercel.app 에 접속해 **실습 시작하기**를 누릅니다.
2. 왼쪽의 문항을 읽고, 오른쪽 성취기준 카드를 점선 상자로 끌어다 놓습니다. 카드를 탭해도 됩니다.
3. 열린 A~E 성취수준 중 문항이 요구하는 수준을 고르고, 필요하면 판단 근거를 메모합니다.
4. **결과·PDF** 화면에서 PDF를 내려받거나 **결과 전송**을 누릅니다.
5. **통계** 화면에서 다른 선생님들의 선택과 비교합니다. '합의도 낮은 순'으로 정렬하면 의견이 갈린 문항부터 볼 수 있습니다.

> 💡 기록은 사용 중인 브라우저에 저장됩니다. 다른 기기에서 이어 하려면 결과 화면에서 **기록 백업(.json)**을 받아 **기록 불러오기**를 하세요.

## 자료 출처

- **성취기준·성취수준**: 『2022 개정 교육과정에 따른 고등학교 정보과 성취수준』 Ⅲ. 고등학교 정보 성취수준 – 1. 성취기준별 성취수준(27~38쪽). 원문 표현을 그대로 수록했습니다.
- **평가 문항**: 연구회에서 수집한 정보 교과 평가 문항 자료. 원본 PDF에서 문항 영역을 그대로 잘라 이미지로 수록했습니다.

문항과 성취수준 자료의 저작권은 각 원저작자에게 있습니다. 연구회 연수·협의 목적으로만 사용해 주세요.

## 데이터와 개인정보

- 전송되는 정보: 문항별로 선택한 **성취기준·성취수준**, 그리고 결과 화면에 입력한 **이름·소속**(선택 입력)
- 전송되지 않는 정보: 분석 근거 **메모**
- 통계 화면에는 **익명 합계만** 표시됩니다. 개별 응답과 이름·소속은 공개되지 않습니다.
- 각 브라우저는 무작위 식별값으로 구분되며, 다시 전송하면 같은 브라우저의 이전 기록이 최신 결과로 바뀝니다.

## 기술 구성

| 구성 | 사용 기술 |
|---|---|
| 프런트엔드 | 단일 HTML 파일 (HTML·CSS·JavaScript, 빌드 과정 없음) |
| 그래프 | SVG로 직접 그린 막대·누적 막대·도넛 그래프 |
| PDF 생성 | [jsPDF](https://github.com/parallax/jsPDF), [html2canvas](https://html2canvas.hertzen.com/) (CDN) |
| 데이터베이스 | [Supabase](https://supabase.com) 무료 플랜 (서울 리전) |
| 배포 | [Vercel](https://vercel.com) (GitHub 저장소와 연결, 커밋 시 자동 배포) |

### 폴더 구조

```
info-std-workbook/
├── index.html      # 웹앱 전체 (화면, 문항·성취기준 데이터, 기능)
├── 1차/img/        # 문항 이미지 q001 ~ q092
├── 2차/img/        # 문항 이미지 q093 ~ q183
└── README.md
```

문항 번호(q001~q183)는 원본 자료의 순서이며, 화면에 보이는 영역별 번호와는 다를 수 있습니다. 이미지 경로는 `index.html`의 `IMG()` 함수에서 정합니다.

### 데이터베이스 (Supabase)

- `submissions` 표: 참여자별 전송 결과 저장 (행 단위 보안 활성화, 방문자는 직접 읽기·쓰기 불가)
- `submit_answers(...)` 함수: 전송 내용을 검사(문항 번호·성취기준 코드·A~E 형식)한 뒤 저장
- `get_stats()` 함수: 문항별 성취기준·성취수준 선택 횟수만 집계해 반환 (이름·소속 제외)

> Supabase 무료 플랜은 일주일 정도 접속이 없으면 프로젝트가 일시정지됩니다. 다시 사용할 때 Supabase 대시보드에서 프로젝트를 재개(Restore)하세요.

## 수정 및 배포

1. 저장소의 파일을 수정해 `main` 브랜치에 커밋합니다.
2. Vercel이 자동으로 다시 배포하며, 보통 1분 안에 사이트에 반영됩니다.
3. 반영 후 브라우저에서 **Ctrl+F5**로 새로고침해 확인합니다.

> `index.html`을 컴퓨터에서 바로 열면 이미지가 보이지 않을 수 있습니다. 이미지 폴더(`1차/img`, `2차/img`)가 `index.html`과 같은 위치에 있어야 합니다. 확인은 배포된 사이트에서 하세요.
